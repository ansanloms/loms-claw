スコープを登録する。既にあれば親を更新する。親は設定のフォールバック解決で辿る。親を持つスコープを登録するときは、親を先に登録する。`/scopes/{scopeId}` 配下の他の operation は、この operation で登録したスコープだけを対象にし、未登録のスコープには 404 を返す。parentId が自分自身のとき、親をたどると自分に戻るとき、親が未登録のときは、継承の解決が終わらなくなるため 400 で拒否する。Discord の client は、チャンネル ID またはスレッド ID をそのままスコープ ID に使い、スレッドの親チャンネルを parentId に渡す。
