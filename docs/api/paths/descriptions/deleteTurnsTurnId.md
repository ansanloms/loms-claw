ターンを 1 件止める。ターン ID は本体が採番し、スレッドをまたいで一意なので、スレッドを指定せずに止められる。実行中のターンは中断し、待機中のターンはキューから外す。中止を受け付けた時点で 202 を返し、完了は `turn.ended` (`result` は `cancelled`) で知る。202 を返した後、止まる前にターンが終わった場合、`result` は `completed` か `failed` になる。client は結果を `turn.ended` の `result` で読む。中止したターンが待っていた承認と質問は、解決済みになる。`approval.resolved` の `decision` と `question.resolved` の `result` が `cancelled` として流れ、`GET /approvals`・`GET /questions` から外れる。該当するターンが無い場合 (既に終わったものを含む) は 404 を返す。`user` の token だけが呼べ、`agent` の token で呼ぶと 403 を返す。
