ターンの経過、定期実行タスクの出力、承認と質問の要求と解決を Server-Sent Events で配信する。threadId で絞らなければ、全スレッドのイベントと定期実行タスクのイベントを 1 接続で受ける。切断中のイベントは再送しない。再接続したら `GET /approvals`、`GET /questions`、`GET /threads/{threadId}/turns` で状態を取り直す。イベントは追加のみで進化させる。client は未知の event と未知のフィールドを無視する。thinking は本体が常に流し、見せるかどうかは client が決める。threadId に未登録のスレッドを指定すると 404 を返す。threadId を省いた要求では 404 は起きない。threadId で絞った購読には、threadId を持たないイベントは流れない。
