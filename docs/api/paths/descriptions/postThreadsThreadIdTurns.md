対象スレッドへ依頼を渡してターンを作る。依頼は対象スレッドのキューに積まれ、会話中のターンがあれば、その後ろで同じセッションを再開して処理する。`model` と `effort` はこのターンだけに効く。省いたら本体の既定値を使う。処理の完了を待たずに 202 と作った `Turn` を返す。経過と結果は `GET /events` の SSE で受け取り、`Turn` の `id` と各イベントの `turnId` を突き合わせる。全ての依頼に、プロンプト先頭に認可ユーザー本人の発話ではない旨の注記が付き、依頼のレート制限 (bot 全体で直近 10 分に 6 回) を超えると 429 を返す。登録されていないスレッドには 404 を返す。
