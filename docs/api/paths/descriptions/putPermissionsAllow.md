常時許可 (`permissions.allow`) の一覧を丸ごと置き換え、置き換えた後の一覧を返す。取り消しは、外したい項目を除いた一覧で置き換える。`user` の token だけが呼べ、`agent` の token で呼ぶと 403 を返す。`agent` がこの operation で、自分のツール実行を自分で常時許可にするのを防ぐためである。`AskUserQuestion` を含む一覧には 400 を返す。常時許可に入ると、質問が利用者に届かず、空の回答で解決されるためである。`GET /permissions/allow` はファイルにある項目をそのまま返すので、ファイルに既に `AskUserQuestion` がある場合、client はそれを除いてから送る。版の検査はしない。`GET` で読んでから `PUT` するまでの間に、承認の `allowAlways` で足された項目は、`PUT` で消える。追加だけなら `POST /approvals/{approvalId}` の `decision: allowAlways` でもできる。
