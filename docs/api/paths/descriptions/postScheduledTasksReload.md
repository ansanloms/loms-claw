定期実行タスクの定義ファイルを再読み込みする。定義の変更を反映する際に使う。`user` の token だけが呼べ、`agent` の token で呼ぶと 403 を返す。`agent` が command 型のタスクを書いてこの operation で有効にすると、ツール承認を通らずにコマンドを実行できるためである。本体は、タスクの定義ファイルを起動時とこの再読み込みの時にだけ読み、読み込んだ時の内容を実行する。`user` の再読み込みで読んだファイルの内容のハッシュを、型を問わず本体が記録する。本体の起動時は、記録と一致するファイルのタスクだけを有効にし、一致しないファイルのタスクは `enabled` が false になり、`user` が再読み込みするまで実行しない。`agent` が書いた、または書き換えたタスクが、利用者の確認なしに有効にならないようにするためである。読み込み時に弾いたタスクは応答の `rejected` に載る。
