# 定数の分類方針

閾値・タイムアウト等の定数は、運用者からの変更要求が出るまで設定化しない (`config.schema.json` / docs / テストの変更コストが見合わないため、2026-08-23 判断 [#133](https://github.com/ansanloms/loms-claw/issues/133))。設定化するときは `config.schema.json` に `default` 付きで追加し `applyConfigDefaults()` で補完する。同じ意味の値を複数箇所に書かない (重複は定数モジュールへの参照に置き換える)。

## 設定化を見送ったもの

設定化の候補に挙がったのは自己メンションレート制限 (max / window)、承認・質問タイムアウト、起動リトライ回数・遅延の 3 群だが、いずれも見送った。理由は、運用者からこれらの値を変更したいという要求が実際に出たことが無く、`config.schema.json` / docs / テストを変更するコストに見合わないため。承認・質問タイムアウトのみ、同じ値を 2 ファイルに独立定義していた重複を解消する目的で `approval/constants.ts` の共通定数へ統合した (値・挙動は変えていない)。
