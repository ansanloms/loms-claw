# メモリ管理

ワークスペースの `memory/` 配下にファイルベースの永続メモリがある。
ディスクに保存したものだけが記憶。隠れた状態は存在しない。

Claude Code 組み込みの auto memory（`~/.claude/projects/` 配下の memory/）は
settings.json の `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` で無効化している。
記憶の保存先はこのルールが定める `memory/` のみ。そちらには書くな。

## ストレージ構成

### memory/MEMORY.md（索引 + 横断的な好み）

長期記憶の入口。各ファイルへの索引と、分野を問わず常に効く好み・方針・制約だけを持つ。
ファイルが存在しなければ `# Memory` という見出しだけのファイルを作成しろ。

保存すべきもの:

- ユーザの好み・方針・繰り返し出る要望
- 重要な判断とその理由
- 過去の会話で確定した事実（運用ルール等）

保存すべきでないもの:

- タスク（→ memory/TODO.md）
- 分野特化の長期知識・台帳（→ memory/knowledge/）
- センシティブな個人情報（→ memory/PRIVATE.md）
- 単発の出来事（→ memory/activity.md の変化ログ）
- コードや git 履歴から導出できる情報

形式:

- 箇条書きで簡潔に。1 項目 1〜2 行。
- カテゴリで分類（例: `## 好み・方針`, `## 買い物`）。
- 古くなった情報は削除または更新しろ。肥大化させるな。長くなる内容は knowledge/ へ切り出して索引からリンクしろ。

### memory/PRIVATE.md（センシティブな個人情報）

住所・身体情報・保険等。**MUST: このファイルの内容を Discord へ投稿するな。** 会話の文脈で言及が必要でも、値をそのまま出力しない。
センシティブな個人情報の追加・更新はこのファイルのみに書き、他のファイルへ複製しない。
ファイルが存在しなければ、上記の MUST をファイル冒頭に記載したうえで作成しろ。

### memory/knowledge/（分野別の長期知識）

所有ギア台帳・登山/ツーリングの教訓など、分野ごとの長期知識。1 分野 1 ファイル（gear.md / hiking.md / touring.md 等）。
新しい分野が必要になったらファイルを増やし、MEMORY.md の索引に追記しろ。

### memory/activity.md（最近の動向）

直近 1 ヶ月のユーザの行動・関心のサマリ。構成は `## 最新動向` と `## ここ1ヶ月の動向`（日付付き変化ログ、30 日で失効）。

- `## 最新動向` は cron ジョブ `check-profiles` が毎日全面更新する。会話セッションからは書き換えない。
- `## ここ1ヶ月の動向` は cron と会話セッションが共有する変化ログ。会話で得た、翌日以降も参照する価値のある出来事・決定は `- YYYY-MM-DD: 内容` 形式でここへ追記しろ（日次メモは廃止した。これが代替）。1 日 1 行、同じ日付の行が既にあれば統合する。

### memory/TODO.md（タスク）

行動の管理。記憶ではない。運用は todo ルールに従う。

### memory/travel/（旅行ノート）

旅行 1 件につき 1 ノート。`travel-note` skill の手順で扱う。

### memory/appendix/（参照資料）

外部由来の参照資料（チェックリスト等）。MEMORY.md の索引からリンクする。

## 参照ルール

- 過去の文脈・ユーザの好み・以前の判断が必要と判断したとき、memory/MEMORY.md を読み、索引から必要なファイルへ降りろ。
- ユーザが最近何をしているか・何に関心があるかを知りたいときは memory/activity.md を読め。
- TODO の参照・更新が必要と判断したときは memory/TODO.md を読め。
- 毎回読む必要はない。文脈から必要性を判断しろ。

## 書き込みルール

- 今後のセッションで参照する価値があると判断したら保存しろ。振り分けは上記ストレージ構成に従う。
- 迷ったら: 分野を問わず常に効く短い事実 → MEMORY.md、分野の知識・台帳 → knowledge/、単発の出来事 → activity.md の変化ログ、やるべき行動 → TODO.md、センシティブな個人情報 → PRIVATE.md。
- 同じ内容を複数ファイルに書かない。昇格・移動したら元の記述を消せ。
- 定期的に MEMORY.md と knowledge/ を見直し、古い・不正確な情報を整理しろ。
