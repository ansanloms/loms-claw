# TODO 管理

`memory/TODO.md` でタスクを管理する。
メモリ（memory/MEMORY.md 等）とは別物。記憶ではなく行動の管理。

## 保存先

`memory/TODO.md`

ファイルが存在しなければ以下の内容で作成しろ:

```markdown
# TODO

| 概要 | 期限 | ステータス | 備考 |
|------|------|------------|------|
```

## 形式

Markdown テーブルで管理する。これは保存形式であって、Discord への提示形式ではない。テーブル記法は Discord では非対応（`discord-markdown` ルール参照）なので、ユーザに見せるときは箇条書きへ変換しろ。

```markdown
# TODO

| 概要         | 期限       | ステータス | 備考            |
| ------------ | ---------- | ---------- | --------------- |
| やること概要 | 2026-04-05 | ⬜         | 補足があれば    |
| 別のやること | なし       | 🔵         |                 |
| 終わったやつ | なし       | ✅         | 2026-03-25 完了 |
```

### カラム定義

| カラム     | 必須 | 説明                                   |
| ---------- | ---- | -------------------------------------- |
| 概要       | yes  | 1 行で収まる簡潔な説明                 |
| 期限       | yes  | `YYYY-MM-DD` または `なし`             |
| ステータス | yes  | 下表の絵文字で表現                     |
| 備考       | no   | 補足・経緯・関連情報。空でも可         |

### ステータス

| 絵文字 | 意味   |
| ------ | ------ |
| ⬜     | 未着手 |
| 🔵     | 進行中 |
| ✅     | 完了   |
| ❌     | 中止   |

## 運用ルール

- ユーザから TODO の追加・更新・削除の指示があったら即座に反映しろ。
- ✅・❌ のタスクは完了・中止から 1 ヶ月経過後に削除して構わない。備考欄の日付で判断しろ。
- ユーザが期限を指定していない限り、勝手に期限を設定するな。`なし` にしろ。ユーザが相対的な期限（「週末まで」「来週」「月末」等）を述べた場合は、現在日付を基準に具体的な `YYYY-MM-DD` へ変換して設定する（範囲を述べたときはその終端日。現在がその期間内なら、猶予が残る直近未来の終端日を採る）。
- ステータス変更時は備考に日付と理由を追記しろ（例: `2026-04-01 完了`）。理由はステータス語（完了・中止等）で足り、特記事項があるときだけ補記する。

## memory との使い分け

TODO は記憶ではなく行動の管理。memory との切り分け・振り分け規則は `memory` ルール（`.claude/rules/memory.md`）を正とする。
