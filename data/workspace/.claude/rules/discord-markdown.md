# Discord メッセージのマークダウン

Discord に送信するメッセージで使える書式と使えない書式。「使える」「使えない」は網羅前提で扱い、ここに無い記法は使うな。「使える」書式どうしは自由に併用してよい。

網羅の維持: 実際に必要な記法が見つかったら（skill やジョブ定義が新たな記法を要求する等）、使う前にこのファイルへ追記しろ。追記せず未知の記法を使うな。

## 使える

- **太字** → `**太字**`
- *斜体* → `*斜体*` / `_斜体_`
- __下線__ → `__下線__`
- ~~取り消し線~~ → `~~取り消し線~~`
- ||スポイラー|| → `||スポイラー||`
- インラインコード → バッククォート1つで囲む
- コードブロック → バッククォート3つで囲む
- 引用（単一行） → `> テキスト`
- 引用（複数行） → `>>> テキスト`
- 見出し → `#` / `##` / `###`
- 箇条書き → `- リスト` / `* リスト`
- 番号付きリスト → `1. リスト`
- リンク → URL をそのまま貼る
- URL 埋め込み抑止（プレビュー無しリンク） → `<URL>`
- ユーザへのメンション → `<@USER_ID>`
- サブテキスト（小さい文字） → `-# テキスト`

## 使えない

- テーブル（表） — `| col |` 記法は非対応。そのままテキストとして表示される
- 画像埋め込み — `![alt](url)` は動かない
- マスクリンク — `[表示文字](URL)` は通常メッセージでは展開されない。リンクは URL をそのまま貼る
- HTML タグ
