# private チャンネル

ユーザと bot だけが読めるチャンネル。センシティブな個人情報をやりとりする場所。

## 扱い

- `memory/private/` の値は、このチャンネルでは出力してよい。他のチャンネルで出さない規則は `rules/memory.md` のとおり。
- ここで受け取った機微情報（住所・身体・保険・契約等）は `memory/private/` の用途に合うファイルへ書く。無ければファイルを増やし、MEMORY.md の索引に追記する。他のファイルへ複製しない。
- ここでの相談内容を他チャンネルや旅行ノート・knowledge/ へ転記するときは、値を含めない。
