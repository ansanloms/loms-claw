# yamareco

ユーザの登山履歴・各山行のタイム/ペース、および登山計画 (予定行程) をヤマレコ (yamareco.com) から取得する skill。

## できること

- 登山計画の所要時間予測
- 過去実績からのペース倍率の集計
- ヤマレコに登録済みの計画の予定行程・距離・累積標高の確認
- 他ユーザの公開計画の横断検索による標準コースタイムの算出

山行リスト・計画リストは API から、個別山行および個別計画の詳細は公開設定のもののみ HTML から抽出する。標準コースタイムを単独で取得する API/HTML は無いが、対象ユーザ本人または他ユーザの登録済み計画 (公開設定) があれば算出できる。対応する登録済み計画が見つからないルートの標準コースタイムはこの skill では取得できず、ユーザに確認する。

## 対象外

- 非公開設定の個別山行・個別計画の詳細
- 対応する登録済み計画が見つからないルートの標準コースタイムの取得 (ユーザへの確認が必要)

## 発動する場面

登山計画の所要時間予測、過去実績からのペース倍率の集計、登録済み計画の予定行程・距離・累積標高の確認を求められたとき。
