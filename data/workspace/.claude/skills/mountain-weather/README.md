# mountain-weather

登山対象の山の天気を、てんくらの登山指数 (A/B/C)・気象庁の麓の天気・Open-Meteo の山頂標高指定の数値予報・標高差からの推定で判断する skill。

## できること

てんくらの登山指数 (A/B/C) を無料のサーバ HTML から取得し、気象庁の麓・登山口周辺の気象と併せて総合判断する。Open-Meteo の山頂標高指定の数値予報 (気温・風・降水・凍結高度) は、CC BY 4.0 の無料 JSON API から取得する。Open-Meteo が取得できない場合は、標高差から山頂気温を推定してフォールバックする。富士山に限り、山頂アメダス (標高 3775m) から気温の実測を取得できる。

## 限界

山頂のピンポイント気象数値そのものは保証されない。指数・麓の天気・数値予報・推定で総合判断し、その限界をユーザに伝える前提。

加えて、次の 3 つは無料ソースでは原理的に取得できないものとして SKILL.md に明記してある。快晴・微風時の岩峰山頂の日射加熱は、夏の暑熱評価で危険側に外す。沢の増水や登山道の状態といった派生ハザードも取得できない。予報士が書く「真冬並みの気温」といった危険度の言語化も同様に取得できない。

## 発動する場面

「◯◯山の天気」「登山の天気」「明日山に登れるか」「登山指数」「山頂の気温」などを聞かれたとき。
